## Analytics Dashboard Queries

The project includes several reusable analytics queries that can be executed directly against the warehouse using Makefile commands.

### Available Dashboard Queries

| Command                           | Purpose                            |
| --------------------------------- | ---------------------------------- |
| `make dashboard-daily-sales`      | Daily sales performance metrics    |
| `make dashboard-monthly-revenue`  | Monthly revenue trends             |
| `make dashboard-top-products`     | Top-performing products by revenue |
| `make dashboard-customer-revenue` | Revenue generated by customers     |
| `make dashboard-order-status`     | Order status distribution summary  |
| `make dashboard-loyalty-revenue`  | Revenue by customer loyalty tier   |

---

### Example Usage

Run daily sales analytics:

```bash
make dashboard-daily-sales
```

Run top product analysis:

```bash
make dashboard-top-products
```

Run customer revenue analysis:

```bash
make dashboard-customer-revenue
```

---

### Query Files

The dashboard commands execute SQL files located in:

```text
analytics/
└── queries/
    ├── daily_sales.sql
    ├── monthly_revenue.sql
    ├── top_products.sql
    ├── customer_revenue.sql
    ├── order_status_summary.sql
    └── loyalty_tier_revenue.sql
```

---

### Warehouse Connection

Each dashboard command connects to the PostgreSQL warehouse using the configured environment variables:

```text
POSTGRES_WAREHOUSE_HOST
POSTGRES_WAREHOUSE_PORT
POSTGRES_WAREHOUSE_USER
POSTGRES_WAREHOUSE_PASSWORD
POSTGRES_WAREHOUSE_DB
```

and executes the corresponding SQL query through `psql`.
